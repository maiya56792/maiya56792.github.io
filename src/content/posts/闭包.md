```python
from collections.abc import Callable

def make_multiplier(scale: float) -> Callable[[float], float]:
    def multiply(x: float) -> float:
        return x * scale
    return multiply

double = make_multiplier(2.0)
print(double(3.0))  # 6.0
```
double就是一个闭包,包含函数和变量值


循环中创建闭包时要注意**延迟绑定**：闭包在调用时才读取外层名字。

```
lenovo@LAPTOP-SE4T4M17:~/project/py$ cat object.py
bad=[lambda :i for i in range(3)]
for i in range(3):
        print(bad[i]())

lenovo@LAPTOP-SE4T4M17:~/project/py$ py object.py
2
2
2
```

Python 函数（包括 lambda）在查找变量时遵循 LEGB 规则：Local（本地）、Enclosing（外层函数作用域）、Global（全局）、Built-in（内建）。lambda 表达式 `lambda: i` 内部并没有定义局部变量 `i`，所以当它被调用执行时，会沿着作用域链向外查找，找到外层作用域中的 `i`.
这里都打印出最后的i.

```
lenovo@LAPTOP-SE4T4M17:~/project/py$ cat object.py
good=[lambda i=i:i for i in range(3)]
print([fn() for fn in good])

lenovo@LAPTOP-SE4T4M17:~/project/py$ py object.py
[0, 1, 2]
```
正确做法是定义局部变量i=调用时的外部变量i
