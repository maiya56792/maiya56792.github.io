看不懂

 __iter__     :进入for循环的时候返回已实现next魔法方法的迭代器
 next    :每次for循环的行为,如果资源已全部迭代完成,抛出stopiteration
 正常每次减一,返回当前值
 ```python
 class Countdown:

    def __init__(self,start):

        self.current=start

    def __iter__(self):

        return self

    def __next__(self):

        if self.current<=0:

            raise StopIteration

        value=self.current

        self.current-=1

        return value

timer=Countdown(3)

for num in timer:

    print(num)
 ```
